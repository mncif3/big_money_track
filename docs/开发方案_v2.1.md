## 一、设计原则与对 v1.1 的修正

| 修正点 | v1.1 方案 | v2.0 调整 | 原因 |
|--------|-----------|-----------|------|
| **核心交付物** | 飞书预警为主 | Web 看板为主，飞书为辅 | 原始需求是网页看板 |
| **数据源** | 裸爬虫东财/同花顺 | akshare 优先 + 代理池 | 减少爬虫维护成本 |
| **存储** | 飞书多维表格 | PostgreSQL (含 TimescaleDB 可选) | 时序分析必须 |
| **主线判断** | 缺失 | 新增"板块主线评分算法" + 龙头识别 | 这是核心诉求 |
| **前端** | 未设计 | React 18 + AntD + ECharts 5 完整方案 | 看板必须 |
| **部署** | 未设计 | docker-compose 单机一键起 | 187:6666 落地 |
| **盘中频率** | 5/15/30 分钟混杂 | 统一 30 分钟 + 代理池兜底 | 降低封 IP 概率 |
| **南向资金** | v1.1 已补充 | v2.0 遗漏，v2.1 补回 | 燊哥要求全量 |

### 4.2 存储与索引策略

- **热数据**（最近 30 天）：常规 PostgreSQL 表 + 复合索引
- **冷数据**（>1 年）：每年 1 月 1 日把 `*_daily` 表归档到 `*_daily_archive_{year}` 分区
- **盘中表**：开启 TimescaleDB 自动压缩（>7 天压缩），或每周 dump 到 archive 后 truncate
- 预估存储：板块日表 ~500 行/天 × 365 ≈ 18 万/年，个股日表 ~5000 × 365 ≈ 183 万/年，3 年累计 < 1 GB，单机完全够用

### 5.2 数据抓取适配器（关键代码骨架）

```python
# backend/app/datasource/base.py
from abc import ABC, abstractmethod
from typing import Optional
import pandas as pd

class FundFlowDataSource(ABC):
    name: str

    @abstractmethod
    async def fetch_sector_flow(self, indicator: str = "今日") -> pd.DataFrame: ...

    @abstractmethod
    async def fetch_stock_flow(self, indicator: str = "今日") -> pd.DataFrame: ...

    @abstractmethod
    async def fetch_north_summary(self) -> pd.DataFrame: ...


# backend/app/datasource/akshare_source.py
import asyncio
import akshare as ak
from .base import FundFlowDataSource

class AkshareSource(FundFlowDataSource):
    name = "akshare"

    async def fetch_sector_flow(self, indicator="今日") -> pd.DataFrame:
        # akshare 是同步的，用 to_thread 包一层
        return await asyncio.to_thread(
            ak.stock_sector_fund_flow_rank, indicator=indicator
        )

    async def fetch_stock_flow(self, indicator="今日") -> pd.DataFrame:
        return await asyncio.to_thread(
            ak.stock_individual_fund_flow_rank, indicator=indicator
        )

    async def fetch_north_summary(self) -> pd.DataFrame:
        return await asyncio.to_thread(ak.stock_hsgt_fund_flow_summary_em)


# backend/app/datasource/manager.py
from typing import List
import logging

logger = logging.getLogger(__name__)

class DataSourceManager:
    """主备数据源管理，失败自动切换"""

    def __init__(self, sources: List[FundFlowDataSource]):
        self.sources = sources

    async def call(self, method_name: str, *args, **kwargs):
        last_err = None
        for src in self.sources:
            try:
                method = getattr(src, method_name)
                df = await method(*args, **kwargs)
                if df is not None and not df.empty:
                    return df, src.name
            except Exception as e:
                logger.warning(f"[{src.name}.{method_name}] failed: {e}")
                last_err = e
        raise RuntimeError(f"All sources failed for {method_name}: {last_err}")
```

### 5.3 代理池集成

部署 `jhao104/proxy_pool` 容器，本地暴露 `http://proxy_pool:5010/get/`。

```python
# backend/app/datasource/proxy.py
import httpx
import random

class ProxyPool:
    def __init__(self, base_url="http://proxy_pool:5010"):
        self.base_url = base_url
        self._cache: list[str] = []

    async def get(self) -> str | None:
        async with httpx.AsyncClient(timeout=3) as cli:
            try:
                r = await cli.get(f"{self.base_url}/get/")
                return r.json().get("proxy")
            except Exception:
                return None

    async def get_all(self) -> list[str]:
        async with httpx.AsyncClient(timeout=3) as cli:
            r = await cli.get(f"{self.base_url}/all/")
            return [item["proxy"] for item in r.json()]
```

> **使用策略**：akshare 自带请求不直接支持代理注入，需 monkey-patch `requests.Session`。盘中高频任务统一通过 `requests.Session` 包装 + 代理 + UA 轮换；日终任务直连即可。

## 六、核心算法 — 主线判断

这是 v1.1 完全缺失的部分，也是用户**首页"主线判断"卡片**的数据来源。

### 6.1 板块"主线评分"模型

针对任意时间窗口（默认 20 个交易日 ≈ 1 月），对每个板块计算：

| 维度 | 计算 | 权重 |
|------|------|------|
| **资金总量** `S_amount` | window 内 main_net_inflow 求和 → z-score 标准化 | 0.35 |
| **持续性** `S_persist` | window 内净流入天数 / window 天数 | 0.25 |
| **强度** `S_strength` | mean(main_net_ratio) | 0.20 |
| **加速度** `S_accel` | 近 5 日均值 / 近 20 日均值 - 1 | 0.10 |
| **板块共振** `S_breadth` | 板块内上涨家数 / 板块总家数 (均值) | 0.10 |

**主线得分**：
```
score = 0.35*S_amount + 0.25*S_persist + 0.20*S_strength
      + 0.10*S_accel  + 0.10*S_breadth
```

取 `score` TOP 3 作为「当前主线候选」。

### 6.2 龙头股识别

对每个 TOP 板块，找其成分股中近 N 日（默认 20 日）：
1. `main_net_inflow_sum` 排名 TOP 30 → 候选池
2. 候选池按以下维度综合排序：
   - 累计主力净流入（权重 0.4）
   - 累计涨幅（权重 0.3）
   - 龙虎榜上榜次数（权重 0.15）
   - 北向持仓占比变化（权重 0.15）
3. 取前 5 名 → 该板块龙头股

### 6.3 算法实现

```python
# backend/app/services/main_thread.py
import pandas as pd
from datetime import date, timedelta
from sqlalchemy import select, func
from app.db import async_session
from app.models import SectorFundFlowDaily, StockFundFlowDaily, StockSectorMap

WEIGHTS = {"amount": 0.35, "persist": 0.25, "strength": 0.20,
           "accel": 0.10, "breadth": 0.10}

async def compute_sector_score(window_days: int = 20) -> pd.DataFrame:
    end = date.today()
    start = end - timedelta(days=window_days * 2)  # 多取一倍方便算交易日

    async with async_session() as sess:
        stmt = select(SectorFundFlowDaily).where(
            SectorFundFlowDaily.trade_date >= start
        )
        rows = (await sess.execute(stmt)).scalars().all()

    df = pd.DataFrame([r.__dict__ for r in rows])
    df = df.sort_values(["sector_code", "trade_date"])

    # 取每个板块最近 window_days 个交易日
    df = df.groupby("sector_code").tail(window_days)

    agg = df.groupby("sector_code").agg(
        amount_sum=("main_net_inflow", "sum"),
        persist_days=("main_net_inflow", lambda x: (x > 0).sum()),
        strength_mean=("main_net_ratio", "mean"),
        recent5=("main_net_inflow",
                 lambda x: x.tail(5).mean() if len(x) >= 5 else x.mean()),
        window_mean=("main_net_inflow", "mean"),
    )
    agg["persist_score"] = agg["persist_days"] / window_days
    agg["accel"] = agg["recent5"] / agg["window_mean"].replace(0, 1e-9) - 1

    # z-score 标准化
    for col in ["amount_sum", "strength_mean", "accel"]:
        s = agg[col]
        agg[f"{col}_z"] = (s - s.mean()) / (s.std() + 1e-9)

    agg["score"] = (
        WEIGHTS["amount"]   * agg["amount_sum_z"] +
        WEIGHTS["persist"]  * agg["persist_score"] +
        WEIGHTS["strength"] * agg["strength_mean_z"] +
        WEIGHTS["accel"]    * agg["accel_z"]
        # breadth 需另算，略
    )
    return agg.sort_values("score", ascending=False)


async def get_top_sectors_with_leaders(top_n: int = 3, leaders_per_sector: int = 5,
                                       window_days: int = 20):
    score_df = await compute_sector_score(window_days)
    top_sectors = score_df.head(top_n).index.tolist()

    results = []
    for sec in top_sectors:
        leaders = await find_sector_leaders(sec, window_days, leaders_per_sector)
        results.append({
            "sector_code": sec,
            "score": float(score_df.loc[sec, "score"]),
            "amount_sum": float(score_df.loc[sec, "amount_sum"]),
            "leaders": leaders,
        })
    return results
```

## 九、预警体系（瘦身版）

原方案分级保留，但**降低盘中频率到 30 分钟**，并把所有预警先写库再推送，避免重复推。

```python
# backend/app/services/alert_engine.py
async def evaluate_alerts():
    rules = [
        north_flow_out_100,         # 北向单日流出>100亿
        north_continuous_outflow_5, # 北向连续5日流出
        sector_outflow_50,          # 单板块流出>50亿
        sector_rotation_speed,      # 板块轮动 >3次/周
        # ...
    ]
    for rule in rules:
        triggered = await rule()
        for alert in triggered:
            if not await alert_already_pushed(alert.hash_key):
                await save_alert(alert)
                await dispatch(alert)  # 飞书 webhook
```

### 12.2 已知问题与对策

| 问题 | 对策 |
|------|------|
| akshare 接口偶发返回空 / 字段改名 | 包一层 schema 校验；保留备用源 efinance |
| akshare 同步 IO 阻塞事件循环 | 统一 `asyncio.to_thread` 包装 |
| 盘中高频抓取被东财限流 | 代理池 + UA 轮换 + 失败指数退避 |
| 板块字典每周可能新增概念板块 | 周一 08:00 自动同步 `sync_sector_meta` |
| 历史回填（首次启动需 1-2 年数据） | 单独脚本 `backfill.py` 调 `ak.stock_sector_fund_flow_hist(symbol=...)` 按板块循环 |
| ETF 申赎数据 T+1 才准确 | etf 任务放在 18:00 |
| 概念板块龙头股识别噪声大 | 龙头算法默认只跑申万一级行业板块，概念板块单独阈值 |
